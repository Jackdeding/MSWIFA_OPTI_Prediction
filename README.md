This repository presents a machine learning framework for predicting the environmental risk of potentially toxic metals (PTMs)  in municipal solid waste incineration fly ash.  

The model integrates multiple algorithms (e.g., XGBoost, Random Forest, SVR, MLP) with SHAP interpretation to identify key influencing factors and improve prediction interpretability.

Models were developed based on python 3.9，scikit-learn version 1.6.1, xgboost version 2.1.4, joblib version 1.4.2,numpy version 2.0.2, shap version 0.47.0 and streamlit version 1.42.1.
